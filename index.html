Install SCImap as an app

SCImap stays a single file, but it can run like a desktop program: its own window without an address bar, a SCImap icon on the Desktop and in the Start Menu, and it can be pinned to the taskbar. This uses the app mode of Edge or Chrome that is already on your PC — nothing else is installed and no internet is needed.

  1. Click Download installer → a file Install-SCImap.cmd is saved.
  2. Double-click it (if SmartScreen asks: More info → Run anyway).
  3. SCImap opens in its own window; right-click its taskbar icon → Pin to taskbar.

The installer copies this file to %LOCALAPPDATA%\SCImap and creates the shortcuts. Your canvases are stored by the browser and are not affected. To update later, open the new SCImap.html and run Install again.

Files & folders

Nothing is uploaded or read — SCImap only records paths. Browsers never reveal a full path, so: type the base folder's full path once (or paste it from Explorer), click Pick… to point at that same folder, and every file or folder you then add from inside it is written out with its full path automatically. Paste paths accepts paths copied from Explorer (“Copy as path”), one or many.
